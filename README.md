## Xuất bản và đăng bài

GitHub Pages cần được đặt ở **Settings → Pages → Build and deployment → Source → GitHub Actions**. Đừng dùng “Deploy from a branch”, vì thư mục `posts/` chỉ chứa Markdown nguồn; GitHub Actions sẽ tạo trang danh sách và từng trang bài viết trong `dist/` trước khi xuất bản.

Để đăng bài, thêm tệp `.md` vào `posts/` theo mẫu trong [HUONG_DAN_DANG_BAI.md](HUONG_DAN_DANG_BAI.md), rồi đẩy thay đổi lên nhánh `main`.
